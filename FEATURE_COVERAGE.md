# Discovery Agent feature coverage

| Original capability | Implemented demonstration / pilot behavior | Remaining service boundary |
|---|---|---|
| Context Blueprints | Six asset categories, scoped requirements, mandatory explanation/evidence/owner/acceptance fields, configurable criticality, added requirements, reasoned exclusions, versioned scope | Larger domain-specific blueprint schemas can be expanded after the pilot |
| Right experts | Expert map with responsibility, process/market coverage, and expertise evidence; invitations and server-enforced roles | Entra registration and company pilot participants must be supplied |
| Contribution experience | Conversations, notes, links, original file storage, audio/screen recording with pause and review, text masking, sharing selection, per-source processing consent | Videos require transcript/screenshots; links are references and are not crawled |
| Gap-driven questions | Ranked initial asks, AI question suggestion, expert-authored follow-ups, expert review before delivery, answer/defer/referral, rationale and effort | Live AI requires its configured service |
| Expert verification | Evidence alongside interpretation; conflict resolution; question and answer gates; critical owner approval; immutable identities and reviewed versions | No enforced two-person separation for administrator overrides |
| Readiness | Captured requirements, verified requirements, required-field coverage, critical blockers, and model evaluation kept separate | Contributor views are permission-filtered |
| Contribution receipts | Receipts for upload, duplicate, answer, extraction and verification; restricted-source dependencies retained | No automatic business-impact claim |
| Missions and recognition | Requirement missions, contribution/verification stages, team milestone, verified-contribution count, optional recognition | No points for upload volume and no monetary reward program |
| Nudges and channels | Live in-app questions; defer/referral; saved quiet-hour/frequency/pause settings; external digest preview; resolved asks close | No scheduled external delivery; Teams/Slack/email remain previews |
| Agent improvement evidence | Expert-reviewed fixed, held-out and regression cases; paired live model runs with same prompts/model/cases; human grading; context/engineering failure routing | Live model service connection needed; sample comparisons are explicitly illustrative |
| Governed refresh | Source revisions, dependency revalidation, audit history, stale evaluations, immutable versioned context exports | Background source connectors and automated monitoring are not connected |
| Rapid integration | JSON package of approved assets, evidence metadata, owners, scope, exclusions, test cases and runs | Export contract only; no claimed Rapid API connection |

The hosted sample uses synthetic campaign rules, personas and sources. It is interactive but does not persist guest edits. The signed-in pilot stores actual records and uploads. Production access and AI are deliberately unavailable until the corresponding services are configured.
